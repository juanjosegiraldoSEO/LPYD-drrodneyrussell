Legacy Links, Cleaned Up

The 16 links to the expired Squarespace site — why there was nothing to redirect, and where each one goes now.

What was wrong

One post carried 16 links to dr-russell-dfm.squarespace.com — an old Squarespace subdomain that now returns 404 “Website Expired” and that the practice no longer controls. The original plan called this a “legacy domain redirect,” but there is nothing to redirect: you can’t configure a redirect on a domain you don’t own. The fix is to clean up the links themselves.

How each link was handled

Repoint where a real page fits · unlink the rest

The links were a “methylation series” pointing to individual articles that were never migrated to the live site. Where a topic genuinely matches an existing page, the link now goes there; where there is no equivalent, the link was removed and the text kept — sending them all to one generic page would mislead readers and Google.

Why these six: environmental toxins → the mold / biotoxin page; DNA, trinucleotide repeats and the X chromosome are genetics → genetic testing; nature & nurture is the methylation concept itself → the MTHFR page; and pregnancy / neural-tube defect is core MTHFR-folate territory → the infertility & miscarriage page.

Not a search-replace job. Swapping the domain in the URL just leaves broken links like https://methylation-heart-disease. This was done by editing the single post directly — unlinking the text or repointing the href, one link at a time.

The content itself — a Plan 02 opportunity

The methylation series was substantial, topical content the site already has authority for (it ranks for MTHFR). If the Squarespace login still works, the 16 articles can be exported and republished on drrodneyrussell.com — at which point each link would point to its own new article instead of being removed. That’s a Plan 02 conversation, not this fix.
